# Branch naming

Name branches `<type>/<short-kebab-case-description>`, with the same `<type>` as the Conventional Commit prefix: `feat`, `fix`, `perf`, `refactor`, `docs`, `test`, `chore`.

- Examples: `feat/mention-in-slash-menu`, `fix/markdown-restore-stale-copy`.
- Describe the change, not the ticket or the date. Keep it under about five words.
- Confirm the proposed branch name with the user before creating the branch.
